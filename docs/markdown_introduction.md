# Markdownについて
以下にプレビューを表示するショートカットを記載します。
ご活用ください。

## ウィンドウを分割してプレビューを表示

- Windows : `Ctrl`+`K` `V`
- Mac : `⌘K` `V`
- Linux : `Ctrl`+`K` `V`

## プレビューを表示

- Windows : `Ctrl`+`Shift`+`V`
- Mac : `⇧⌘`+`V` ←ホンマ？
- Linux : `Ctrl`+`Shift`+`V`

## markdownに目次をつけたいとき

`ctrl`+`shift`+`p` > Markdown All in One: 目次（TOC）の作成

## VSCode以外で便利に書きたいと思ったら
ZettlrなどのMarkdownエディタを利用してみて下さい。
