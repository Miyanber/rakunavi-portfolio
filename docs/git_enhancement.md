# Git 開発メモ

実際の開発における、便利なコマンドを掲載しています。コピペ用です。

## .gitignoreの内容が反映されない時

Gitにキャッシュが残っています。キャッシュを削除しましょう。

```bash
git rm -r --cached . # ファイル全体キャッシュ削除
git rm -r --cached 'ファイル名'    # ファイル指定してキャッシュ削除
```

基本キャッシュ全削除で問題ないです。

## ブランチが大量発生している

開発を進めていると、使い終わったブランチが大量発生する場合があります。そんな時は以下のコマンドで不要なブランチを削除してしましましょう。

```bash
# リモートで削除されたブランチが git branch -r の一覧から消えます。
git fetch --prune 
# リモートに存在しないローカルブランチを一括削除します。(MacOS, Linux)
git branch --merged | grep -vE "\*|main|master" | xargs git branch -d 
```

Windowsの方は、2番目のコマンドは以下のコマンドを代わりに使用して下さい。

```shell
# リモートに存在しないローカルブランチを一括削除します。(Windows)
git branch --merged | Where-Object { $_ -notmatch '^\*|main|master' } | ForEach-Object { git branch -d $_.Trim() }
```

## ブランチを最新にする際によくわからない画面が出た

自分のブランチで作業していると、マージ先のブランチが別のプルリクエストのマージ等で先に更新される場合があります。
その場合、自分のブランチを、マージ先のブランチの状態に更新したいを思うことがあるでしょう。
その際、マージ先のブランチ（以後アップストリームブランチと呼びます）を自分のブランチにマージしようとすると、コミットメッセージを書くよう促される場合があります。
これは正常な動作であります。ただ、エディタをどうやって閉じればいいのか、又一回一回開くのは面倒という場合もあるでしょう。その為に以下のコマンドを紹介しておきます。

```bash
# コミットメッセージを予め指定しておいてからマージ
git merge main -m "Merge main into topic-branch"

# コミットメッセージを自動メッセージで済ます
git merge main --no-edit
```

以上のコマンドのどちらかを利用すれば良いです。
