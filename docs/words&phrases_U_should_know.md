## 知っておくべき単語とフレーズ
マニュアル群で使用される、理解すべき単語を簡単にまとめました。

1. Django（ジャンゴ）
	PythonでWebアプリを作れるもの。
2. ドメイン
	インターネット上の住所で、google.comとかrakunan-h.ed.jpみたいなやつ。
3. DB
	データベース。データを保存する巨大な表と思えば分かりやすい。
4. スーパーユーザー
	一般的に、最高で全ての権限を持つユーザー。らくなびでは管理側しか持っていませんし、渡してもいけません。
5. 文化祭補助生徒
	らくなびと同じくして誕生した枠組み。生徒が文化祭運営に深く携われるよう、また教職員の負担削減（？）のために生徒が一部の仕事を補助します。椅子・机の分配、展示の基準を満たすかの立ち入り調査など仕事がありますが、この部門の一つに我々がいるイメージです。9月はじめに各学級担任から募集があるので、らくなびに関わるなら応募して下さい。締切に遅れても、個別で相談して見て下さい。24, 25年度の担当は木村先生（陸上部顧問）でした。
6. Github
   世界中の開発者御用達の、複数人やチーム・組織でコードを共有・公開したり管理できる**Web上の**サービス。gitというツールと接続し、開発の多くはそのgitで行います。
   １つのプロジェクトをリポジトリという単位で呼びます。
7. 依存関係
	ピザを作るにはパンやチーズが必要ですが、チーズをつくるには牛乳が必要で、それには牛さんを連れてこなくてはいけません。らくなびも同様に、動作には他のプログラムが必要で、それらを依存関係と呼びます。
	大きく種類あり、
	- Python（pip）の依存関係
		更新についてはdevelopers_memo.mdにありますが、Pythonでは、開発するプロジェクトごとに必要となるプログラムの環境を分離して、関係ないプログラム同士が混ざらない方針（仮想環境）が強く推奨されています。これは「あるプログラムにはバージョンAAAが必要なのに、他のプログラムにはバージョンBBBが必要だ」というカオスを避けるためです。Djangoなど、 `requirements.txt` に含まれるものはこれらです。
	- システムの依存関係
	  pipのインストール時に必要になったり、weasyprintなどpipではない出処で依存している場合があります。
