## 変更点

sports\_fesの作り直しに重点を置いた変更でした

### 体育祭アプリの大幅仕様変更
DBの再設計、運用を見据えた簡単な操作を意識した調整を行いました。まだデザインや運用面で不安はありますが、これらは後に解決して行きます。

### エラーページの再設計
実はЯなどに特定の条件でアクセスすると500エラーが発生していました。エラーページをDjango公式のマニュアルに沿う形で再設計し、動作することも確認しました。CSRFエラーや400エラーのページも追加し、現在のエラーページは
- 400 Bad Request
- 403 Permisson Denied
- 403 CSRF Token Error
- 404 Not Found
- 500 Internal Server Error
の5つになりました。

### 審査後の編集を禁止
2026年度からの運用について、審査の負担軽減のため、審査合格後のコンテンツについては編集を認めない形になりました。

#### 最適化
コンテクストプロセッサや、get_permission等大量に使用する関数についてキャッシュを利用して大幅な改善を図りました。
