# 2025年度実運用, 10月4日バージョン

## 注目すべき変更点（前リリース比較）
### １：新Indexデザイン「枯山水」
西堀君のデザインが元になっています。迷走していたIndexも、ようやくそれらしく落ち着きました。
### ２：校内Mapの仕様変更
電子黒板を切り捨てた影響で、来場者向けの地図を、「校内に貼ってある合言葉で認証する」方法に変更しました。
（そもそも公開はセキュリティ的に危ないので）
合言葉での認証はFestivalDateで設定された最終日の終了時刻まで可能です。
### ３：展示タイムテーブルの本実装
これだけ遅れていたようですね。ライブ同様、タイムテーブルにしっかり表示されます。
