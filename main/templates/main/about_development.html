開発について

らくなびの開発にあたって、技術的な情報を公開しています。

フレームワーク

らくなびは、Pythonのフレームワーク Django （公式サイトopen_in_new） を利用しています。
Djangoはセキュリティが高く、柔軟で拡張性があるため、多くの企業や団体で採用されています。

出典open_in_new

準拠・対応している技術

以下に準拠・対応しています。

  • PWA（プログレッシブWebアプリ）
    • Webサイトとは思えない、ネイティブアプリのような体験を可能にします。普通のアプリのようにインストールすることも可能です。
    出典open_in_new {% comment %}
  • CSP（コンテンツセキュリティポリシー）
    • サイバー攻撃の１つ、クロスサイトスクリプティング （XSS） からの低減のために、追加の強力なセキュリティレイヤを提供します。 {% endcomment %}
  • Webp・AVIF画像配信
    • 画像の配信で従来広く使用されてきたJPEGやPNGなどのフォーマットに代わり、より軽量で先進的なAVIFで画像を配信しています。 AVIFが利用できない場合でも、十分軽量な形式Webpを利用（フォールバック）できます。
    © Google LLC, 出典open_in_new © 2019 The Alliance for Open Media, 出典open_in_new
  • zstdエンコーディング
    • リソースをZstandard（zstd）という圧縮率の高い形式で圧縮することにより、より高速な配信を実現します。
    © Facebook, Inc., 出典open_in_new
  • View Transition API
    • ページ遷移の際に、滑らかなアニメーションでユーザー体験を向上させます。一部のブラウザではご利用いただけません。 ブラウザの対応状況open_in_new

開発における創意工夫

  • ライト・ダークテーマ
    • 初回読み込み時にユーザーの設定を検出し、最適なテーマを自動で適用しています。フッターのボタンで手動変更もできます。
  • ナビゲーションバー
    • 多くのサイトではナビゲーションバーが上に配置されることが多いですが、下に配置することによって、スマートフォンアプリのような体験を可能にしています。
  • クエリ最適化
    • データベースから最低限のクエリでデータを取得し、いわゆるN+1問題を解消。レスポンスの改善に繋げました。
  • クラスベースビュー（CBV）
    • Djangoにおけるクラスベースビューによってコードの再利用性と保守性を高めつつ、拡張性を持たせることができています。
  • QRコードでの共有
    • フッターにあるQRコード生成ボタンで、ご覧のページのQRコードを生成できます。共有時に便利です。（「QRコード」は株式会社デンソーウェーブの登録商標です。）
